# Sheriff Gestures 🤠

A fun classroom tool to randomly select Sheriff Victoria’s victory gestures with a rolling effect.

## How to use
- Click “¡Elegir gesto!”
- Watch the gestures roll
- Perform the selected gesture as a class

## Notes
- You can add new gestures directly in the app
- Works in any browser (no installation needed)

## Purpose
This tool is part of a classroom routine to increase engagement and make learning more interactive through storytelling and movement.
